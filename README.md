# Titanic Dataset – Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The objective is to understand the dataset, identify missing values, detect outliers, analyze relationships between variables, and discover meaningful insights through data visualization.

## 📂 Dataset Description
The Titanic dataset contains passenger information such as:
- Passenger ID
- Passenger Class
- Name
- Gender
- Age
- Number of Siblings/Spouses
- Number of Parents/Children
- Ticket
- Fare
- Cabin
- Embarked
- Survival Status

## 🛠️ Tools & Technologies
- Python
- Jupyter Notebook
- VS Code
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🔍 Tasks Performed

1. Imported required Python libraries.
2. Loaded the Titanic dataset.
3. Explored the first five rows of data.
4. Checked dataset information and dimensions.
5. Generated statistical summaries.
6. Identified missing values and their percentages.
7. Analyzed categorical data using value counts.
8. Created data visualizations.
9. Detected outliers using boxplots and the IQR method.
10. Analyzed relationships using scatterplots and correlation heatmaps.
11. Handled missing values using Median, Mode, and Unknown category.
12. Saved the cleaned dataset as a CSV file.
13. Extracted key insights from the dataset.

## 📊 Data Visualizations
The following visualizations were created:

- Survival Countplot
- Gender-wise Survival Analysis
- Age Distribution Histogram
- Fare Distribution Histogram
- Age and Fare Boxplots
- Age vs Fare Scatterplot
- Correlation Heatmap
- Pairplot

## 🧹 Data Cleaning
Missing values were handled as follows:

- Age: Filled using Median.
- Cabin: Filled with "Unknown".
- Embarked: Filled using Mode.

The cleaned dataset was saved as `titanic_cleaned.csv`.
